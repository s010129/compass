# 轉盤向心力感測器

手機螢幕朝上平放在旋轉桌（轉盤）上，用內建加速度計把水平方向的加速度即時分解成
**向心分量（紅色箭頭，指向圓心）** 與 **切線分量（綠色箭頭，沿速度方向）**，
兩個箭頭的長度都正比於各自的大小。概念參考 phyphox 的向心加速度實驗。

可安裝的 PWA，離線可用，圖示是 Minecraft 風格的羅盤（指針會指向圓心方向）。

## 怎麼用

1. 手機螢幕朝上平放在轉盤上並固定好。
2. 轉盤靜止時按 **歸零校正**，扣掉桌面沒完全水平造成的重力分量。
3. 按 **開始測量**，然後轉動轉盤。
4. 轉速穩定後可按 **鎖定圓心方向**，讓切線分量的讀值更乾淨。
5. 按 **匯出 CSV** 取得原始資料。

沒有手機在手邊時，按 **示範模式** 會模擬一個「加速 → 等速 → 煞車」的轉盤。

## 方向是怎麼定出來的

裝置座標為 **+x 螢幕右、+y 螢幕上、+z 穿出螢幕**。

- **正負號慣例**：螢幕朝上平放時，規範下 `accelerationIncludingGravity.z ≈ +9.8`，
  iOS 回傳的正負號相反。程式由 z 軸讀值自動判斷慣例並修正，慣例確定前不做任何計算。
- **向心方向**：修正後，量到的水平分量就等於真實加速度的水平分量（重力只有 z 分量），
  方向直接指向圓心。
- **不顛倒**：canvas 的 y 軸向下、裝置 +y 向上，繪圖時對 y 取負號；
  另外用 `screen.orientation.angle` 補償橫豎屏。
- **切線方向**：ω > 0（從螢幕上方往下看為逆時針）時 t̂ = (ĉ_y, −ĉ_x)。
  旋轉方向由陀螺儀 `rotationRate.alpha` 判斷，也可手動指定。
- **圓心方向的估計**：圓周運動的加速度是 `h = r·[ω²·ĉ + ω̇·rotate(ĉ, −90°)]`，
  h 的方向會從圓心方向偏掉 `φ = atan2(ω̇, ω²)`（與半徑無關）。
  程式把量到的方向轉回 `+φ` 再做低通，所以轉盤加速或煞車時，
  圓心方向的估計不會被切線分量帶歪。
- **推算值**：半徑 `r = a_c / ω²`，線速度 `v = ω·r`。

## 檔案

```
index.html              頁面
styles.css              樣式
src/app.js              量測、分解與繪圖
src/mc-compass.js       Minecraft 風格羅盤的像素畫產生器（瀏覽器與 icon 共用）
tools/gen-icons.mjs     產生 PWA icon（node tools/gen-icons.mjs，無外部相依）
manifest.webmanifest    PWA manifest
sw.js                   Service worker（離線快取）
```

重新產生 icon：

```sh
node tools/gen-icons.mjs
```

所有運算都在手機端完成，不會上傳任何資料。
